# Data Quality Pipeline

A Python and PySpark based data quality pipeline with automated testing and CI/CD using GitHub Actions.

## Project Goals

- Read raw customer data
- Perform data quality validation
- Transform valid records
- Write clean data in Parquet format
- Automate testing using PyTest
- Implement CI/CD using GitHub Actions
- Containerize the application using Docker

## Tech Stack

- Python
- PySpark
- PyTest
- Git
- GitHub Actions
- Docker
- AWS
